# Student Marks Prediction

A beginner-friendly Machine Learning project that predicts student marks based on study hours.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm

Linear Regression

## Project Steps

1. Created a student dataset
2. Explored the data using Pandas
3. Visualized the relationship between study hours and marks
4. Split the data into training and testing sets
5. Trained a Linear Regression model
6. Evaluated the model using Mean Absolute Error
7. Predicted marks for new students

## Key Finding

The dataset shows a positive relationship between study hours and student marks.

## Project Type

Machine Learning / Regression
